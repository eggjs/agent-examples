# Agent Examples for [egg](https://github.com/eggjs/egg)

Agent development examples using [tegg](https://github.com/eggjs/tegg).

## Usage

```bash
git clone git@github.com:eggjs/agent-examples.git
cd agent-examples

# choose an example
cd mini-muse
npm install
npm start
```

## List of examples

- [mini-muse](mini-muse) - AI-powered web application generator using Claude
